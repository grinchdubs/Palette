# BorderlessTD

Package `FNS_BorderlessTD`.

Borderless TouchDesigner window, plus timeline hiding.

- Category: Interface
- Version: 3.2.12
- Access: Free
- Docs: https://functionstore.tools/docs/fns-borderlesstd/

## What it does

- **Hide the title bar**: Shows and hides TouchDesigner's window title bar on one key.
- **Hide the timeline**: Shows and hides the timeline on one key.
- **Escape back to the title bar**: `Shift+Esc` always brings the title bar back, until you switch that safety net off.
- **Start borderless**: The project can open borderless, with the timeline already hidden.
- **Full screen or windowed**: Keeps a borderless window full screen, or lets it sit in a smaller window or a window zone.
- **Pause indicator**: While playback is paused, a part of TouchDesigner's UI changes colour, standing in for the hidden timeline's pause cue.
- **Hide the menu bar links**: Hide Menu Buttons removes the Wiki, Forum and Tutorials links from the menu bar.
- **Show the project name in the menu bar**: Show Project Name puts the project's file name in the menu bar, where the hidden title bar used to show it.

## Reach it

`op.FNS_BORDERLESS_TD` is its global shortcut: call its promoted methods on that object from anywhere in the project.

## Promoted API

No promoted API: the package has no extension. Its parameters, listed below, are its surface.

## Commands

- **Toggle borderless** (id `toggleborderless`): Toggle the borderless TouchDesigner main window. Method `ToggleBorderless` on `BorderlessWindow`.
- **Toggle fullscreen** (id `togglefullscreen`): Toggle fullscreen on the TouchDesigner main window. Method `ToggleFullscreen` on `BorderlessWindow`.
- **Toggle timeline** (id `toggletimeline`): Show or hide the timeline bar. Method `ToggleTimeline` on `HideTimeline`.

## Hotkeys

- `F7` (`Shortcutmakeborderless` on `FNS_BorderlessTD`)
- `alt.F7` (`Shortcut` on `FNS_BorderlessTD`)

## Alternative for

None.

## Requires

- `FNS_ConfigRegistry`
- `FNS_MainMenuRegistry`
- `FNS_ToolbarRegistry`

## Parameters

### BorderlessWindow

- **Shortcut** (`par.Shortcutmakeborderless`, Str), default `F7`: Key that shows and hides the window's title bar. Windows only.
- **Borderless State** (`par.Borderless`, Toggle), default `off`: Whether the title bar is hidden right now. Toggling this is the same as pressing the shortcut.
- **Use Shift-Esc to undo** (`par.Shiftesc`, Toggle), default `off`: Let Shift+Esc put the title bar back. Worth having while you get used to a borderless window; TouchDesigner has no window controls without one.
- **Show Project Name** (`par.Showprojectname`, Toggle), default `off`: Show the project file's name in the menu bar. Handy once the title bar, which normally carries it, is hidden.
- **Hide Menu Buttons** (`par.Hidemenubuttons`, Toggle), default `off`: Remove the Wiki, Forum and Tutorials links from the main menu bar.
- **On Start** (`par.Onstart`, Toggle), default `off`: Go borderless as soon as the project opens, rather than waiting for the shortcut.
- **Fix Fullscreen On Start** (`par.Fixfullscreenonstart`, Toggle), default `off`: Re-assert full screen shortly after the project opens. On by default because TouchDesigner does not reliably start full screen on its own.
- **Force Full Screen (always)** (`par.Fullscreen`, Toggle), default `off`: Keep the window full screen whenever it is borderless. Turn it off to run TouchDesigner borderless inside a window zone instead of over the whole display.
- **Enable** (`par.Active`, Toggle), default `off`: Turn the borderless-window feature on. Off leaves TouchDesigner's window exactly as the OS drew it and the shortcut does nothing.

### HideTimeline

- **Shortcut** (`par.Shortcut`, Str), default `alt.F7`: Key that shows and hides TouchDesigner's timeline.
- **Enable** (`par.Activetimeline`, Toggle), default `off`: Turn the timeline-hiding feature on. Off leaves the timeline alone and the shortcut does nothing.
- **Hide Timeline** (`par.Statetimeline`, Toggle), default `off`: Whether the timeline is hidden right now. Toggling this is the same as pressing the shortcut.
- **State on Startup** (`par.Stateonstartuptimeline`, Toggle), default `off`: Whether the timeline starts hidden when the project opens.
