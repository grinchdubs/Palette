# ParHoverMIDI_VSN1

Adjust any parameter by hovering over it and turning an endless MIDI encoder, built for the Intech Studio VSN1 with screen and LED feedback: parameter slots and banks, ParGroup control, step sizes, shortcuts for reset and clamp, and network zoom when no parameter is under the mouse. Lands at the network root; one instance per project.

- Category: Control & mapping
- Version: 1.9.0
- Access: Free
- Docs: https://function-store.github.io/TD_ParHoverMIDI_VSN1/

## What it does

- **Hover and turn to adjust**: Hover the mouse over any parameter and turn an endless relative MIDI encoder to change it; any such encoder works for this, the VSN1 included.
- **Screen and LED feedback**: The VSN1's screen shows the parameter under the mouse and its LEDs show state.
- **Step size switching**: The buttons under the VSN1 screen switch the step size the encoders use.
- **Save a parameter to a slot**: Long-press a primary button to save the hovered parameter to a slot.
- **Recall slots across banks**: Saved parameters come back instantly across banks, without hunting for them again; long-press the step buttons to switch banks.
- **Reset, default and clamp shortcuts**: Device buttons run shortcuts for reset, default and clamp on the hovered parameter.
- **ParGroup control**: Parameter groups such as RGB or XYZ turn as one; this needs TouchDesigner 2025.
- **Zoom and pan the network**: With no parameter under the mouse, the encoders zoom and pan the network editor.
- **Show custom parameter help**: Holding Alt over any custom parameter of the component shows its help.
- **Update in place from GitHub**: Checks its GitHub releases from its About page and updates in place, keeping your slot data when you externalize the component first.

## Reach it

No global shortcut. Installed beside the toolkit root at the project root, as `op('/ParHoverMIDI_VSN1')`; its promoted methods are called on that COMP.
