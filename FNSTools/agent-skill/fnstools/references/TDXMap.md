# TDXMap

MIDI controller mapping with a live web UI: multiple devices, banks, Smart Learn, button actions, 14-bit controls. Pro adds smoothing, pickup mode, easing curves, slot and modify modes.

- Category: Control & mapping
- Version: 1.2.0
- Access: Free
- Docs: https://tdxmap.functionstore.xyz/docs/

## What it does

- **MIDI mapping by drag and drop**: Drag a parameter onto a knob, fader or button in a web UI served from inside your project to map that MIDI control to it.
- **Controller banks per device**: Switch banks independently on each MIDI device you map.
- **Learn controls with Smart Learn**: Smart Learn works out what the hardware sends.
- **Button actions**: Maps buttons to actions as well as continuous controls.
- **Read 14-bit controls**: Reads 14-bit controls, for controllers that send them.
- **Install from the toolkit picker**: Lands at the network root, where `op.TDXMap` resolves from anywhere, and keeps working with the toolkit removed.
- **Update in place**: Checks for updates from its own preferences footer and reloads the new build in place.
- **Smoothing, pickup and easing in Pro**: Pro adds smoothing, pickup mode, easing curves, slot and modify modes.
- **Mappings outlive the trial**: Without a licence, live MIDI to parameters keeps working and your mappings are kept.

## Reach it

No global shortcut. Installed beside the toolkit root at the project root, as `op('/TDXMap')`; its promoted methods are called on that COMP.
