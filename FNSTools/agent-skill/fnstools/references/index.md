# FNSTools packages (v3.2.76)

One line per package: category, summary, docs link, what it is an alternative for. The page of the same name under this folder has the detail.

- **ChopBank** (CHOPs & sensing, v1.0.5, Base): A bank of channel processors: one block per channel, each with its own range, exponent curve, zero-below, lag and speed mode, built from the input with one Snap Input, with gain before and after and every block promoted as a property. An alternative for the Math CHOP and the Constant CHOP. [docs](https://functionstore.tools/docs/chopbank/) Alternative for `constantCHOP`, `mathCHOP`.
- **ChopProcess** (CHOPs & sensing, v1.0.5, Base): Shapes channels in one node: limit, remap between ranges with an exponent curve, zero at the bottom, lag, and an optional speed mode that turns the result into a running total. An alternative for the Math CHOP. [docs](https://functionstore.tools/docs/chopprocess/) Alternative for `mathCHOP`.
- **CircularDistortionTOP** (Visual, v1.0.5, Base): A circular distortion for images: rings of displacement around a centre you place, with phase, frequency, amplitude and a mode blend, and a choice of how the input extends past its edge. [docs](https://functionstore.tools/docs/circulardistortiontop/)
- **ColorGen** (Visual, v1.0.4, Base): A colour palette generator: a lookup of any length shaped by a phase step per channel and per channel exponents, with a lookup ramp as a second output. [docs](https://functionstore.tools/docs/colorgen/)
- **ColorGenPro** (Visual, v1.0.4, Pro): A cosine palette generator in GLSL: the full coefficient set per channel, an RGB and D mode, blackout and soft regions, and a lookup ramp as a second output. [docs](https://functionstore.tools/docs/colorgenpro/)
- **ComplexMix** (Visual, v1.0.4, Free): Combines two UV fields as complex numbers: add, subtract, multiply, divide or raise one to the other, optionally weighted by a third input, then samples an image through the result. [docs](https://functionstore.tools/docs/complexmix/)
- **ComplexOp** (Visual, v1.0.4, Free): Treats the image plane as the complex plane and applies a complex function to it: square, root, exp, log, the trigonometric and hyperbolic families, with iteration, a pre and post transform and a choice of edge handling. [docs](https://functionstore.tools/docs/complexop/)
- **ConstantCHOP** (CHOPs & sensing, v1.0.5, Base): A Constant CHOP with typed values: numbers, toggles, tuples, text, paths or operator references, each promoted as a property you can read and set from Python, and a snap from its input. An alternative for the Constant CHOP. [docs](https://functionstore.tools/docs/constantchop/) Alternative for `constantCHOP`.
- **CookBar** (Network, v1.0.7, Free): Draws a bar above every operator in the network you are viewing: its cook time on top, its GPU memory below, so the expensive parts of a network stand out at a glance, with the numbers beside them if you like. A Top List in a corner names the heaviest operators and takes you to one with a click. Its toolbar button switches it on; Ctrl+right-click the button for a global Hog CHOP to stress-test against. Based on Anton Heestand's Cook Bar. [docs](https://functionstore.tools/docs/cookbar/)
- **EaseInterpolator** (CHOPs & sensing, v1.0.5, Base): Crossfades between two CHOPs through an easing curve: thirty classic easings from sine to bounce, or a custom curve from a third input, all driven by one Select value. [docs](https://functionstore.tools/docs/easeinterpolator/)
- **ExpressionPOP** (3D and Particles, v1.0.6, Free): Per-point attribute expressions for POPs: write lines like P = P + N * 0.1 and they compile to a GLSL compute shader, with local variables carried between lines. An alternative for the Math Combine POP. [docs](https://functionstore.tools/docs/expressionpop/) Alternative for `mathcombinePOP`.
